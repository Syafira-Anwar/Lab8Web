//Lab 8 - Pemrograman Web: Aplikasi CRUD Data Barang (PHP & MySQL)//

Proyek ini merupakan tugas praktikum modul Lab 8 Pemrograman Web (OBE) yang mengimplementasikan manajemen data barang secara dinamis (Create, Read, Update, Delete) menggunakan PHP Native dan database MySQL / MariaDB, dilengkapi fitur unggah berkas gambar (file upload).

📌 Fitur Utama

Read (index.php): Menampilkan seluruh daftar data barang dalam bentuk tabel interaktif.

Create (tambah.php): Menambahkan data barang baru beserta unggah foto/gambar barang ke server.

Update (ubah.php): Mengubah informasi barang (nama, kategori, harga jual/beli, stok) dan memperbarui gambar.

Delete (hapus.php): Menghapus data barang dari database dengan konfirmasi tindakan.

Database Connection (koneksi.php): Penghubung antara aplikasi PHP dan server MySQL.
